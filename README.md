# Neuron χ² Starter

A portfolio starter with Next.js + Tailwind CSS.

## Development Setup

- Requires Node.js >= 18.18.0 (use `nvm use` to match the project `.nvmrc`).
- Install dependencies with `npm install`.
- Run the dev server with `npm run dev`.
- Production preview: `npm run build` followed by `npm run start` (serves on http://localhost:3000).
